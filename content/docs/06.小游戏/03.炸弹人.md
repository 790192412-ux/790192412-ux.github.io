红白机时代的经典单屏爆破游戏。**纯 Canvas + 原生 JS**，零依赖，带 8-bit 音效。

## 玩法

- 方向键 / WASD 移动，**空格**放炸弹
- 炸弹炸开软砖，可能掉落道具：

| 道具 | 效果 |
|---|---|
| 🔥 火力 | 爆炸范围 +1（最多 7 格） |
| 🧨 炸弹 | 同时能放的炸弹数 +1（最多 6 个） |
| 👟 速度 | 移动速度 +0.55 格/秒 |

- 炸掉**全部敌人** → 出口（金色）打开 → 走过去进入下一关
- 死法有两种：被敌人碰到、被自己的炸弹炸到。**第二种是新手最常见的死法**
- 三条命，每关敌人更多更快

## 难度档位

| 档位 | 初始敌人 | 敌人速度 | 引信 | 软砖密度 |
|---|---|---|---|---|
| 简单 | 2 | 2.0 格/秒 | 2.9 秒 | 72% |
| 普通 | 3 | 2.5 格/秒 | 2.4 秒 | 78% |
| 困难 | 4 | 3.1 格/秒 | 2.0 秒 | 84% |

引信越短，你从炸弹旁边跑开的时间窗口越小 —— 这是难度最直接的来源。每两关敌人 +1（最多 7 个）。

## 移动手感是怎么做的

没用"自由像素 + 碰撞检测"那套（容易卡墙角），而是**格子对齐 + 插值**：每次只走到下一个格心，到了格心才允许转向。

好处是**永远不会卡在墙角**，代价是转向最多延迟一格的时间（速度 2.6 格/秒时约 0.38 秒）。这也是很多红白机游戏的原始手感。

## 音效是实时合成的

这个游戏（以及本站其他小游戏）的音效**一个音频文件都没有** —— 全部用 Web Audio 的振荡器实时生成：方波、三角波、噪声三个通道，正好是红白机 2A03 音源芯片的架构。HUD 右上角可以一键静音，设置会记住。

## 想自己改

打开 `static/games/bomberman/index.html`，顶部的 `DIFFS` 对象就是难度表：

```js
var DIFFS = {
  easy:   { n:2, spd:2.2, fuse:2.9, brick:0.72, eSpd:2.0 },
  normal: { n:3, spd:2.6, fuse:2.4, brick:0.78, eSpd:2.5 },
  hard:   { n:4, spd:3.0, fuse:2.0, brick:0.84, eSpd:3.1 }
};
```

`n` 初始敌人数、`spd` 玩家速度、`fuse` 引信秒数、`brick` 软砖概率、`eSpd` 敌人速度。`CW / CH` 改地图格数，`genMap()` 里的 `x % 2 === 0 && y % 2 === 0` 决定硬墙的排布规律。
