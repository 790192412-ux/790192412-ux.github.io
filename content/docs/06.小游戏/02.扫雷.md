经典扫雷，**纯 DOM + 原生 JS** 实现，零依赖，带 8-bit 音效。

## 玩法

- **第一下保证不会踩雷**（雷是在你第一次点击之后才布的，而且点击格周围的 8 格也一起排除）
- 左键翻开 · 右键插旗
- 手机：**长按格子插旗**，或者先打开「标记模式」再点
- 数字表示它周围 8 格里有几颗雷；点空格会连锁展开
- **通关时间按难度分别记录**，破纪录会有提示

## 难度档位

| 档位 | 尺寸 | 雷数 | 雷密度 |
|---|---|---|---|
| 初级 | 9 × 9 | 10 | 12.3% |
| 中级 | 16 × 16 | 40 | 15.6% |
| 高级 | 30 × 16 | 99 | 20.6% |

高级就是经典 Windows 扫雷的专家档。棋盘宽度会自动适配容器，格子在窄屏上会等比缩小（最小 7px）。

## 音效

翻开会响（只有当次真的展开出新格子才响，避免连锁展开时刷屏）、插旗有单独的轻响、踩雷是噪声合成的爆炸、通关是上行和弦。音效全部是 Web Audio 振荡器实时合成的，仓库里没有任何音频文件。

## 想自己改

打开 `static/games/minesweeper/index.html`，最上面就是难度表：

```js
var LEVELS = {
  easy: { cols:9,  rows:9,  mines:10, cls:'easy' },
  mid:  { cols:16, rows:16, mines:40, cls:'mid'  },
  hard: { cols:30, rows:16, mines:99, cls:'hard' }
};
```

加一档就再加一行，然后在页面上的按钮组里补一个 `<button data-level="xxx">`。`cls` 对应 CSS 里的字号档位（`.board.easy / .mid / .hard .cell`），格子越小字号要越小。
